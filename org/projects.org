#+DESCRIPTION: Project List

Here's a non-exaustive list of the projecs we currently maintain:

+ [[https://github.com/byzantine-systems/chrysopolis][Chrysopolis]]: A verified foundation for BEAM applications, based on seL4, Nix and LionsOS.
+ [[https://github.com/byzantine-systems/eparch][Eparch]]: A Gleam wrapper for Erlang's ~gen_statem~ and ~gen_event~.
+ [[https://github.com/byzantine-systems/ergon][Ergon]]: A library to leverage newer PostgreSQL's temporality and Graph features for background job processing.
+ [[https://github.com/byzantine-systems/pacta][Pacta]]: An experimental library for "Session Types" in Gleam, built atop of
  Eparch and the ~gen_statem~ behavior.
+ [[https://github.com/byzantine-systems/pharos][Pharos]]: A "plugin-based" monitor and alert manager for BEAM Nodes and Hosts.
